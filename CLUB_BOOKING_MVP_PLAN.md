### Ключевое открытие
SENET уже решает проблему на уровне клуба (real-time статусы ПК, карта зала, бронирование), но нетудобного агрегатора для пользователя. LANGAME — агрегатор, но не имеет глубокой интеграции с SENET в Казахстане.

**Наша ниша:** Прослойка-агрегатор между SENET (и другими системами) и пользователем. Показываем свободные места ВО ВСЕХ клубах рядом на одной карте.

### Риски (честно)
1. **Бюджет $200 — это ноль.** Серьёзно. Этого хватит на домен + хостинг на 1 месяц и maybe кофе разработчику.
2. **Нет контактов с клубами.** Продукт строится на гипотезах.
3. **SENET API требует токена от каждого клуба.** Без договорённостей с клубами API не дадут.
4. **SENET ID и Booking Module уже существуют.** Если клубы уже купили модуль бронирования SENET — зачем им ты?

## 2. MVP Scope (v0.1)

### Что делаем
Web-приложение (PWA) + Telegram Bot (как fallback).

**Пользовательский сценарий #1: Поиск мест**
1. Пользователь открывает сайт/бота
2. Видит карту Караганды с маркерами клубов
3. Рядом с каждым клубом — количество свободных ПК сейчас
4. Нажимает на клуб — видит схему зала: свободные (зелёные) и занятые (красные) места

**Пользовательский сценарий #2: Бронирование (упрощённое)**
1. Выбирает свободный ПК на схеме
2. Указывает время (например, "+2 часа")
3. Оставляет номер телефона (бронь подтверждается звонком от клуба)
4. Клуб получает уведомление (Telegram/email)

### Что НЕ делаем в v0.1
- ❌ Оплата онлайн (сложно, долго, compliance)
- ❌ Регистрация/логин (только номер телефона)
- ❌ Пополнение баланса Steam (как в LANGAME)
- ❌ Нативные мобильные приложения (только PWA)
- ❌ Расширение на кафе/рестораны
- ❌ Админка для клубов (клубы продолжают работать в SENET)

### Что оставляем на v0.2+
- Онлайн-оплата бронирования
- Push-уведомления
- Программа лояльности
- Отзывы и рейтинги клубов

## 3. Архитектура (SENET Integration)

```
Пользователь (браузер/Telegram)
        │
        ▼
   ┌─────────────────────┐
   │  Frontend (PWA)     │
   │  React/Vanilla JS   │  ← хостится на Vercel/Netlify ($0)
   └────────┬────────────┘
            │
            ▼
   ┌─────────────────────┐
   │  Backend (API)      │
   │  Node.js/Express    │  ← хостится на Railway/Render ($5-7/мес)
   │  или Python/FastAPI │
   └────────┬────────────┘
            │
            ├──────────────────────────────┐
            ▼                              ▼
   ┌──────────────────┐          ┌──────────────────┐
   │  SENET API       │          │  Telegram Bot    │
   │  (per-club)      │          │  (уведомления    │
   │  GET /workstations│          │   клубам)        │
   │  POST /users     │          └──────────────────┘
   │  POST /workstations/login
   └──────────────────┘
```

### Как получаем данные из SENET
```javascript
// Запрос к SENET API клуба
GET https://{club}.api.enes.tech/workstations/
Authorization: Bearer {club_token}

// Ответ:
[
  { id: 1, name: "ПК-01", status: "free", zone: "VIP", 
    specs: { cpu: "i7", gpu: "RTX 3070", ram: "32GB" }},
  { id: 2, name: "ПК-02", status: "busy", zone: "VIP",
    specs: { cpu: "i7", gpu: "RTX 3070", ram: "32GB" }},
  // ...
]
```

**Проблема:** Нужен API-токен от каждого клуба. Решение:
- v0.1a: Админ клуба даёт токен через Google Form (ручной ввод)
- v0.1b: Помогаем настроить интеграцию (по телефону)
- v0.2: Автоматическая self-service регистрация

### Telegram Bot (быстрый старт)
```python
# Команды бота
/start — приветствие, отправка геолокации
/kz — показать клубы рядом со свободными местами
/club {id} — показать схему зала (текстовую)
/book {pc_id} {hours} {phone} — забронировать
```
