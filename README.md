# 🎮 OpenCode — PC Club Booking System

Система бронирования ПК-клубов (PC Club Booking System) — полностью онлайн бронирование рабочих мест в компьютерных клубах, без звонков администратору.

## Архитектура

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│   Frontend    │────▶│   Backend    │────▶│  Mock SENET  │
│  Vanilla JS   │     │  Express TS  │     │   (порт 9000)│
│  Vite :5173   │◀────│  :8000       │◀────│              │
└──────────────┘     └──────┬───────┘     └──────────────┘
                            │
                     ┌──────▼───────┐     ┌──────────────┐
                     │   SQLite DB   │     │ Telegram Bot │
                     │ better-sqlite3│     │  (уведомл.)  │
                     └──────────────┘     └──────────────┘
```

## Состав проекта

| Компонент | Технологии | Описание |
|-----------|-----------|----------|
| **backend** | Node.js, Express, TypeScript, better-sqlite3 | API-сервер (авторизация, бронирования, клубы, игры) |
| **frontend** | Vanilla JS, Vite, Leaflet | Клиентская часть (карта клубов, бронирование, личный кабинет) |
| **mock-senet** | Node.js, Express | Мок-сервер SENET для управления рабочими станциями |
| **telegram-bot** | Node.js, TypeScript, node-telegram-bot-api | Бот для уведомлений о бронированиях |
| **cloudflared** | Python | Утилита для туннелирования (Cloudflare Tunnel) |

## Быстрый старт

```bash
# Установка зависимостей
cd bookclub/backend && npm install
cd ../frontend && npm install
cd ../mock-senet && npm install
cd ../telegram-bot && npm install

# Настройка
cp .env.example .env  # отредактировать под своё окружение

# Запуск (из корня bookclub/)
cd bookclub && docker-compose up
# или по отдельности:
# backend: npm run dev (порт 8000)
# frontend: npm run dev (порт 5173)
# mock-senet: npm start (порт 9000)
```

## Ключевые возможности

- 🗺️ **Карта клубов** на Leaflet с кластеризацией
- 💺 **Визуальная схема зала** с выбором мест
- ⏰ **Бронирование временных слотов** (например 17:00–21:00)
- ✅ **Мгновенное подтверждение** без участия администратора
- 📱 **Авторизация по телефону** через SMS
- 💰 **Пополнение баланса** и покупка пакетов времени
- 🤖 **Telegram-уведомления** о бронированиях
- 🔌 **Интеграция с SENET** для управления станциями
